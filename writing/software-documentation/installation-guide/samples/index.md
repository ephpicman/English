# Installation Guide: Five Examples

Five original examples for **Installation Guide**, written for the genre and audience implied by the corresponding template. Names, dates, and metrics are illustrative; adapt them to the real brief.

---

## Example 1: A university mentoring programme

## Prerequisites
- Node.js 20 or later
- Git and npm
- Access to the project repository

## Install
```bash
git clone https://example.com/acme/task-service.git
cd task-service
npm ci
cp .env.example .env
npm run dev
```

## Verify
Open `http://localhost:3000/health`. A successful response contains `{"status":"ok"}`. Set credentials locally; never commit secrets.
