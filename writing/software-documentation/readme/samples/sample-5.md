# A workplace policy

A lightweight project supporting a workplace policy.

## Features
- Clear setup and usage instructions
- Consistent validation and useful errors
- Automated tests for core behaviour

## Quick start
Run `npm ci`, copy `.env.example` to `.env`, configure required values, then run `npm run dev`.

## Development
Run `npm test` before opening a pull request. Report reproducible issues with expected and actual results; never include credentials.
